# Цифры

Тренажёр образов, запоминания цифр, двоичных последовательностей и цифр на слух.
Работает как статический сайт: серверная база данных и сборка не нужны.

## Запуск

```sh
python3 -m http.server 8000 --directory .
```

Для публикации раздавайте все файлы репозитория по HTTPS, включая `features.js`,
`features.css`, `manifest.webmanifest`, `sw.js` и `icons/`. Подкаталог проекта
GitHub Pages поддерживается; пути манифеста и Service Worker относительные.

## Свои образы и резервные копии

Внизу раздела «Теория» откройте «Мои образы и данные». Выберите число, измените
слово и описание, при желании добавьте PNG/JPEG/WebP до 1 МБ. Сохранённое слово
принимается в тренировках вместо стандартного. Картинка показывается в карточке
и при раскрытии ответа. Кнопка «Вернуть стандартный» удаляет замену для этого
числа, сохраняя статистику.

«Скачать резервную копию» создаёт JSON с настройками, статистикой, своими
образами, состоянием адаптации и записями голоса. Синхронизации с облаком нет.
Данные находятся в браузере; очистка данных сайта может их удалить. Храните
копию в надёжном месте. Импорт принимает файлы до 32 МБ, проверяет формат и
требует подтверждения замены. Ошибка проверки не меняет данные. При ошибке
сохранения импорта выполняется откат; голос заменяется одной транзакцией.
Переносите копии только между доверенными устройствами.

## Адаптация и разбор ошибок

В настройках цифр, битов и аудио включите «Подбирать сложность по моим
результатам». Три последовательных результата от 90% увеличивают длину ряда
на 20%; три результата ниже 60% уменьшают её на 20%. Между этими порогами
сложность сохраняется. После изменения серия результатов сбрасывается.
В аудио также меняется интервал между цифрами; в битах длина округляется до
кратной трём. Ограничения длины и темпа сохраняются. Настройки показывают
параметры следующего ряда. При отключённой адаптации используются ручные
параметры; повторное включение начинает подбор заново.

После воспроизведения появляется «Разбор ошибок»: позиции, ожидаемые и
введённые значения, пропущенные/неполные образы, соседние перестановки,
нарушение порядка и перестановки цифр внутри образа. Это объяснение наблюдаемого
ответа, а не диагностика причины ошибки в памяти.

## PWA и обновления

После первой успешной загрузки на HTTPS сайт сохраняет необходимые файлы и
английские аудиозаписи для работы без сети. Статус показан в «Мои образы и
данные». В поддерживающих установку браузерах появляется кнопка «Установить
приложение»; можно также использовать меню браузера. На iPhone: Safari →
«Поделиться» → «На экран “Домой”». Локальные записи голоса продолжают храниться
в IndexedDB. Микрофону требуется разрешение, а системные голоса зависят от
устройства и могут требовать сети.

Новая офлайн-версия сначала загружается в отдельный кеш. Кнопка «Обновить
приложение» активирует её и перезагружает страницу; тренировку перед этим
следует закончить. Никаких автоматических перезагрузок во время тренировки
нет. Старый кеш приложения удаляется после активации новой версии; данные
пользователя не удаляются.

После изменения файлов приложения обновите версию кеша перед публикацией:

```sh
python3 tools/update-pwa-cache.py
python3 tools/update-pwa-cache.py --check
```

Версия вычисляется из содержимого файлов. CI проверяет, что `sw.js` обновлён.
Список кешируемых файлов поддерживается в `sw.js`; при добавлении обязательных
ресурсов добавьте их туда и в список assets генератора.
